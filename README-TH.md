# เว็บติดตามงานออกแบบ ChaemGraphic (ขึ้นเว็บฟรีด้วย GitHub Pages)

ผลลัพธ์: เว็บที่ `https://ชื่อผู้ใช้.github.io` เช่น `https://chaemgraphic.github.io`
ลูกค้าเปิดดูสถานะงานได้ ส่วนคุณเข้าสู่ระบบเจ้าของร้านเพื่อเพิ่ม ลบ เลื่อนขั้น และใส่รูปได้

ไฟล์ในชุดนี้
- `index.html` หน้าเว็บทั้งหมด
- `data/orders.json` ข้อมูลงาน (มีตัวอย่าง 3 งาน ลบทิ้งได้ภายหลัง)
- `README-TH.md` ไฟล์นี้

---

## ขั้นที่ 1 สมัคร GitHub และตั้งชื่อ

1. ไปที่ https://github.com/signup แล้วสมัครด้วยอีเมล
2. ตอนตั้ง Username ให้ใช้ `chaemgraphic` ชื่อนี้จะกลายเป็นชื่อเว็บของคุณ (`chaemgraphic.github.io`)
3. ถ้าชื่อถูกใช้แล้ว ให้ลองชื่ออื่น เช่น `chaemgraphic-th` หรือ `chaem-graphic` ชื่อเว็บจะเปลี่ยนตามชื่อที่ได้

## ขั้นที่ 2 สร้าง repository

1. กดปุ่ม **New** (หรือไปที่ https://github.com/new)
2. ช่อง Repository name ต้องตั้งเป็น `ชื่อผู้ใช้.github.io` ให้ตรงตัวพอดี เช่น `chaemgraphic.github.io`
3. เลือก **Public**
4. กด **Create repository**

## ขั้นที่ 3 อัปโหลดไฟล์

1. แตกไฟล์ zip ในเครื่อง
2. ในหน้า repository กด **uploading an existing file** (หรือ Add file แล้ว Upload files)
3. ลาก `index.html` และโฟลเดอร์ `data` เข้าไปในหน้า (แนะนำให้ใช้ Chrome จะลากโฟลเดอร์ได้)
4. กด **Commit changes**

ถ้าลากโฟลเดอร์ไม่ได้: อัปโหลด `index.html` ก่อน แล้วกด Add file แล้ว Create new file พิมพ์ชื่อไฟล์เป็น `data/orders.json` (พิมพ์ `/` แล้วระบบจะสร้างโฟลเดอร์ให้) แล้วคัดลอกเนื้อหาจากไฟล์ `data/orders.json` ไปวาง

## ขั้นที่ 4 เปิดใช้งานเว็บ

1. ในหน้า repository ไปที่ **Settings** แล้วเลือก **Pages** ในเมนูซ้าย
2. ตรง Source เลือก **Deploy from a branch**
3. ตรง Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1-2 นาที แล้วเปิด `https://ชื่อผู้ใช้.github.io` จะเห็นหน้าเว็บ

## ขั้นที่ 5 สร้างโทเคนสำหรับแก้ไขงาน (ทำครั้งเดียว)

โทเคนคือรหัสที่ให้หน้าเว็บบันทึกข้อมูลลง repository ของคุณได้

1. กดรูปโปรไฟล์มุมขวาบน แล้วเลือก **Settings**
2. เลื่อนลงล่างสุดในเมนูซ้าย เลือก **Developer settings**
3. เลือก **Personal access tokens** แล้วเลือก **Fine-grained tokens** จากนั้นกด **Generate new token**
4. ตั้งชื่อ เช่น `chaemgraphic-site` และตั้งวันหมดอายุนานที่สุดที่เลือกได้
5. ตรง Repository access เลือก **Only select repositories** แล้วเลือก repository `ชื่อผู้ใช้.github.io` ของคุณ
6. ตรง Permissions เปิดหัวข้อ Repository permissions หา **Contents** แล้วเลือก **Read and write**
7. กด **Generate token** แล้วคัดลอกรหัสที่ขึ้นต้นด้วย `github_pat_` เก็บไว้ก่อน (หน้านี้จะแสดงรหัสครั้งเดียว)

ชื่อเมนูใน GitHub อาจต่างจากนี้เล็กน้อยตามเวลา แต่หลักการเดียวกัน คือโทเคนที่แก้ไฟล์ใน repository นี้เท่านั้น

## ขั้นที่ 6 เข้าสู่ระบบเจ้าของร้าน

1. เปิดเว็บของคุณ เลื่อนลงล่างสุด กด **เข้าสู่ระบบเจ้าของร้าน**
2. วางโทเคนแล้วกด **เข้าสู่ระบบ**
3. จะเห็นป้าย "โหมดเจ้าของร้าน" ฟอร์มเพิ่มงาน และปุ่มจัดการในแต่ละการ์ด
4. ลบงานตัวอย่าง แล้วเริ่มเพิ่มงานจริงได้เลย

โทเคนจะถูกเก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น ถ้าจะใช้เครื่องอื่น ให้วางโทเคนอีกครั้ง

## ข้อควรรู้

- **ลูกค้าเห็นการเปลี่ยนแปลงช้าประมาณ 1-2 นาที** เพราะ GitHub ต้องอัปเดตหน้าเว็บหลังทุกครั้งที่บันทึก
- **ข้อมูลงานและรูปเป็นสาธารณะ** เพราะ repository เป็น Public และทุกคนที่รู้ลิงก์เห็นทุกงาน อย่าใส่ข้อมูลส่วนตัวของลูกค้า เช่น เบอร์โทร ที่อยู่ ในหน้านี้
- **อย่าส่งโทเคนให้ใคร** ใครมีโทเคนจะแก้ไขเว็บคุณได้ ถ้าโทเคนรั่ว ให้กลับไปที่หน้า Fine-grained tokens แล้วลบโทเคนนั้นทิ้ง แล้วสร้างใหม่
- **ผู้ใช้ GitHub ที่ไม่มีโทเคน** ลูกค้าไม่เห็นปุ่มแก้ไขใดๆ และแก้ไขข้อมูลไม่ได้
- **ถ้าจะซื้อโดเมนของตัวเองทีหลัง** (เช่น chaemgraphic.com) ไปที่ Settings แล้วเลือก Pages แล้วใส่ Custom domain ได้ ไม่ต้องทำเว็บใหม่
- **เปลี่ยนเบอร์โทรหรือชื่อแบรนด์:** แก้ในไฟล์ `index.html` ตรงบรรทัด `var BRAND=` และ `var PHONE_TEXT=` ได้โดยกดไอคอนดินสอที่ไฟล์ในหน้า repository
